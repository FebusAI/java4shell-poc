# Security policy

This repository documents and reproduces a third-party JVM defect
(CVE-2026-114938). It is research tooling, not a production library.

- Found a bug in the PoC/tooling? open a GitHub issue.
- Findings about the underlying CVE belong to the OpenJDK/Oracle process
  (see JDK-8393212). Coordinated disclosure: security@febusai (GPG on request).
- Treat running this code against remote hosts as an active-security test:
  authorization is mandatory (see LICENSE ethical-use addendum).
